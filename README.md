### Editor

This is my project to replace nvim as my daily driver.

There's nothing wrong with nvim. It's great. I just want an editor that does exactly what I want it to do and nothing more

I also want it to be a single, statically compiled binary that I can drop into any unix-type environment and it does everything I want it to do with zero configuration or external dependency.

For me, "everything I want it to do" is:

- Fuzzy file finder
- Project wide search
- Modal editing
- LSP (maybe... I'm not sold on this as a solution yet)
- A few commands and hotkeys to run commands

Maybe more ideas will come to me, but that's about it.

This is my editor. No one else should use it.
